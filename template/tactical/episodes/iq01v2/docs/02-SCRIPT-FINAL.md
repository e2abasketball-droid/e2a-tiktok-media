# 02 · Hooks and final script (V2)

## Three hooks considered
| | Hook | Type | Verdict |
|---|---|---|---|
| A | "Three teammates. One right pass." | Competitive challenge | **Master.** It sets the rule of the game in 2.3 s and works with letters already on the screen. |
| B | "One defender gives this whole play away." | Curiosity gap / defensive read | **Alternative version.** It points the viewer at the defence without naming who. |
| C | "Here, the best pass is the longest one." | Counterintuitive | True for this possession (C is the longest pass, 8.3 m), but it gives away the answer before the question. Rejected. |
